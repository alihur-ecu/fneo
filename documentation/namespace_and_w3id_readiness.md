# Namespace

| Item | Value |
| --- | --- |
| Prefix | `fneo:` |
| Namespace | `https://w3id.org/fneo/` |
| Ontology IRI | `https://w3id.org/fneo/ontology` |
| Version IRI | `https://w3id.org/fneo/ontology/0.1.0-rc2` |
| Shapes stem | `https://w3id.org/fneo/shape/` |

The shapes stem is not a second term namespace.

`https://w3id.org/fneo/` is the identifier used in the ontology and the published graphs. Registration is requested in [perma-id/w3id.org#7103](https://github.com/perma-id/w3id.org/pull/7103) and is not merged. A request to the namespace returned HTTP 404 on 2026-10-31. The files are available from this repository and from https://alihur-ecu.github.io/fneo/.

The proposed redirect rules are in `w3id/fneo/`. They send HTML requests to GitHub Pages and RDF serialisations to the `v0.1.1` ontology files. Those rules take effect when the W3ID pull request is merged.
