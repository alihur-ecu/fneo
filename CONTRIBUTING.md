# Contributing

This tree is a development candidate. The public repository URL is
TO BE ADDED AT PUBLIC RELEASE. Do not open a pull request until that
repository exists.

Ontology changes that alter class axioms, property characteristics, domains,
ranges, individuals, or public term IRIs need a new version and an entry in
`ontology/CHANGELOG.md`.

Do not add MEANTIME manual annotations to the operational graphs. Do not
relicense source-bearing TextGraphs as MIT or CC0. Do not commit credentials.
