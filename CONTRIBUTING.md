# Contributing

Issues and pull requests are welcome on https://github.com/alihur-ecu/fneo.

Ontology changes that alter class axioms, property characteristics, domains, ranges, individuals, or public term IRIs need a new ontology version and an entry in `ontology/CHANGELOG.md`.

Do not add MEANTIME manual annotations to the operational graphs. Do not relicense source-bearing TextGraphs as MIT or CC0. Do not commit credentials.
